| Проверка | Детали |

## 📥 УСТАНОВКА

### 1. Получите токен бота
```
Напишите @BotFather → /newbot → скопируйте токен
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

Или отдельно:
```bash
pip install python-telegram-bot==21.6
pip install httpx==0.27.0
pip install python-whois==0.9.4
pip install dnspython==2.6.1
```

### 3. Настройте config.py
Откройте `config.py` и вставьте:
```python
BOT_TOKEN = "1234567890:ABC-ВАШ-ТОКЕН"
VIRUSTOTAL_API_KEY = ""  # Опционально
```

### 4. (РЕКОМЕНДУЕТСЯ) Получите VirusTotal API ключ

**Для лучших результатов:**
1. Зарегистрируйтесь на https://www.virustotal.com
2. Перейдите в https://www.virustotal.com/gui/my-apikey
3. Скопируйте FREE API ключ (бесплатный)
4. Вставьте в config.py:
```python
VIRUSTOTAL_API_KEY = "ваш_ключ_от_virustotal"
```

### 5. Запустите бота
```bash
python bot_advanced.py
```

## ⚙️ КАК ЗАПУСТИТЬ НА СЕРВЕРЕ

### На Linux (Ubuntu)

1. **Установите Python 3.10+**
```bash
sudo apt update
sudo apt install python3.10 python3-pip
```

2. **Создайте директорию проекта**
```bash
mkdir ~/security-bot
cd ~/security-bot
```

3. **Установите зависимости**
```bash
pip3 install -r requirements.txt
```

4. **Создайте systemd-сервис**

Создайте файл `/etc/systemd/system/security-bot.service`:
```ini
[Unit]
Description=Advanced Security Check Bot
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/security-bot
ExecStart=/usr/bin/python3 /home/ubuntu/security-bot/bot_advanced.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

5. **Запустите сервис**
```bash
sudo systemctl daemon-reload
sudo systemctl enable security-bot
sudo systemctl start security-bot
sudo systemctl status security-bot
```

6. **Просмотр логов**
```bash
sudo journalctl -u security-bot -f
```
